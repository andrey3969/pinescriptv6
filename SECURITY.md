# Security policy

## Maintainer and responsibilities

**Project and security maintainer:** [Andrey (@andrey3969)](https://github.com/andrey3969).

The maintainer receives and assesses security reports, reviews proposed changes
for security impact, coordinates fixes, and publishes advisories when warranted.

## Supported scope

This policy covers the Pine Script source and documentation on this repository's
current default branch. When reporting an issue, identify the affected file and
commit. Older revisions may be assessed by checking whether the issue is present
on the current default branch.

ChronoForge is a TradingView indicator that produces plots and alert conditions.
Reports about the TradingView platform itself belong with TradingView.

## Report a vulnerability privately

Open this repository's [Security advisories page](https://github.com/andrey3969/pinescriptv6/security/advisories)
and select **Report a vulnerability** to use GitHub's private reporting channel.
If the reporting control is unavailable, open an issue titled **Private security
contact requested** without including vulnerability details; the maintainer can
arrange a private reporting channel.

Include:

- The affected file and commit.
- A concise description of the issue and its security impact.
- Minimal steps to reproduce it in a test environment you control.
- A suggested fix, if available.

Do not include credentials, API keys, broker tokens, personal trading records,
or other confidential information. Share sensitive technical details privately
rather than in public issues or pull requests.

## Triage and coordinated disclosure

The maintainer will assess the report, attempt to reproduce the issue safely,
and discuss remediation and disclosure with the reporter. Confirmed issues will
be addressed through a reviewed change, with a public advisory when appropriate.
Reporter credit will be coordinated with the reporter.

Handling is on a best-effort basis; no response deadline or bounty is promised.
