## Record real reuse

When another developer independently uses this code in a public project, record:

1. The external repository or public script URL and its owner.
2. A permalink to the exact commit/file that uses the code, with attribution or
   a clear reference to this repository.
3. The source commit or release reused and the purpose it serves.
4. The date the link and actual use were checked.
5. Whether it is an independent project, a derivative, or a maintainer-owned demo.

Maintainer-owned demos must be labeled as such and excluded from the external
dependent total. An unchanged fork or a stated intention to use the code is not
verified integration. Do not count the same project twice.
